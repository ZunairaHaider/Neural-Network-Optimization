# Poster

- `poster.pdf`: the compiled poster (DIN A0, portrait).
- `poster.tex`: LaTeX source (`tikzposter`, TUM style files included in this folder). Build with
  `pdflatex poster.tex` (run twice).
- `poster_overleaf.zip`: the same source as a self-contained bundle that can be uploaded to Overleaf.

A few extra PNGs (`fig_*`, `dataset_panel_v2.png`) are copies of figures from `results/` left over
from an earlier poster iteration; the current poster uses only `dataset_viz_poster.png` and the TUM logo.
