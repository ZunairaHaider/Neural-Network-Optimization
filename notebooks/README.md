# Notebooks

- `convergence_analysis.ipynb`: convergence of the constructive search versus pruning on six
  synthetic problems.
- `models_summary.ipynb`: summary of the PMSM stator-winding models built by the constructive
  search (static estimator and dynamic twin), loaded from `patenting/motor/outputs/`.
- `_build_models_summary.py`, `_append_start_topo.py`, `_rebuild_init_robustness.py`: scripts
  that generate or extend the notebooks above.
